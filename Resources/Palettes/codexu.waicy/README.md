# WAICY 流彩 · 1001v1

Color-token-only palette for AiGoodBro, based on the actual WAICY badge candidate made on October 1, 2026.

The color source is WAICY/work/WAICY工牌/1001v1: README.md identifies three candidate layouts, design-source-1001v1.json records them, and layout.py:34–35 defines the shared background. The inspected pure-badge comparison export uses the same pink-orange flow. This theme references their colors; it does not select a badge layout or claim official endorsement.

The actual badge gradient is #FE478A → #FF7CA0 → #FFA74D, with #FFFAF6 paper and #352832 ink. Its A/B/C descriptive paper values are #FFF7EF/#FFFAF6/#FFF8F4. The wider WAICY guideline uses a nearby but different gradient, #F43F8E → #FF7AA8 → #FF9F5E; those guideline values are not substituted for the badge's actual values here.

Both variants retain the actual three-stop colors in data.valueProgress and the quota gradient roles. Light control and quota text uses deeper pink/orange shades; dark controls use brighter shades. The surface tint is capped at 6%. Font sizes, primary text and semantic status colors remain system/application roles. The app's native material renderer provides the glass background; this package only supplies palette colors.

The asset manifest is empty. No WAICY logo, mascot, badge artwork, texture or font is copied. The MIT license covers this palette configuration and documentation, not WAICY trademarks or source artwork.

Version 1.0.0 corresponds to this 1001v1 adaptation. Verification is recorded with the application palette regression evidence.
