# GitHub Primer

Color tokens adapted from the GitHub Primer design system for AiGoodBro.

- Light variant follows primer.style light functional colors (accent `#0969DA`, success `#1A7F37`, attention `#9A6700`, danger `#CF222E`).
- Dark variant follows GitHub dark dimmed/functional colors (accent `#4493F8`, success `#3FB950`, attention `#D29922`, danger `#F85149`).
- Heatmap uses the GitHub contribution-graph greens.
