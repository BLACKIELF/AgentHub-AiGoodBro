# 紫蓝流光 · Violet Glow · 1001v1

A background presentation variant of the existing codexu.default palette for AiGoodBro.

Both tokens/light.json and tokens/dark.json are byte-for-byte copies of the original codexu.default token files. Their blue-violet colors and original MIT attribution are retained. This package gives that existing palette an independent, non-default identity for the native glass background renderer; it is not a newly designed color scheme.

The original default package stays unchanged. Fresh settings and Reset continue to select codexu.default. This package can be selected separately as 紫蓝流光 / Violet Glow. The asset manifest is empty; no new decorative artwork is included.

Version 1.0.0 corresponds to this 1001v1 presentation variant. Token equivalence and the unchanged default are covered by palette regression checks.
