# TypeSafe AI 安装与使用

版本：0919v1。AiGoodBro 随应用携带的本机 Skill 副本；不含 API Key、SDK、账户配置或调用结果。

在首页点击「前往 Codex 安装」，核对预填指令后发送。若未预填，粘贴已复制的指令。
安装前检查用户级 skills 目录的同名和近似项：相同复用，有差异先确认，不静默覆盖。
将本文件所在文件夹完整复制到当前 Codex 用户级 skills 目录，保留 `SKILL.md`。
如果新 Skill 没有出现在列表，开启新任务或重启 Codex 后检查。

使用：请用 `$typesafe-ai` 把这个产品判断拆成 Choice、Noul 或 Score，给出所需 state、置信度门槛和代码侧的失败处理。

安装 Skill 不等于安装 `@typesafe-ai/sdk`，也不等于授权 API 调用。密钥只通过本机环境变量提供，不写入 Skill、项目、日志或安装指令；真正接入前应读取 TypeSafe 最新文档，并让确定性规则和副作用继续由代码控制。
