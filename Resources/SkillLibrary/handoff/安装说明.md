# handoff 安装与使用

版本：0919v1。AiGoodBro 随应用携带的可移植版；不含密钥或账户配置，不需要下载才能安装 Skill。

在首页点击「前往 Codex 安装」，核对预填指令后发送。若未预填，粘贴已复制的指令。
安装前检查用户级 skills 目录的同名和近似项：相同复用，有差异先确认，不静默覆盖。
将本文件所在文件夹完整复制到当前 Codex 用户级 skills 目录；保留 SKILL.md 和所有 references。
如果新 Skill 没有出现在列表，开启新任务或重启 Codex 后检查。

使用：请用 $handoff 为当前项目保存一份可续接交接，列出已经验证的成果、未完成事项和下一步。\n\n或：请用 $handoff 读取此项目的现有交接，核验当前文件后继续。所有资料留在任务所属项目，不新建全局全文镜像。
