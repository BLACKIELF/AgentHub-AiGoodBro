# Handoff 任务交接

> 0919v1 可移植打包版：源自本机 handoff 0908v1 兼容入口，内附现用协作规范的 File Placement 与 Cross-Session Handoff 两节，移除个人路径依赖。没有修改本机原 Skill。

开始交接或接手前，完整读取 [交接规范](references/collaboration.md)。
按现有项目定位交接文件；项目已有专属规则时优先沿用，不创建全局全文镜像。
沿用任务内有效授权；只有讨论或审阅时不写文件，用户要求保存交接时才写必要文件。
只记录可核验状态、有效产物、未完成事项和最小下一步；已验证与待验证分开。
API Key、认证材料和未脱敏私人信息不写入交接。完成交接不等于原任务完成。
交付可点击的交接路径和一条简短续接指令，不关闭应用、不切换账号，也不擅自安装、发布或调用付费服务。
