完整 ZIP 含英文原 MP4。Git 仓库 `docs/showcase/1012v1/` 不含该视频二进制，需要先下载到该目录的 `exports/AiGoodBro-English-1011v1.mp4`，再打开 `index.html` 播放；缺文件时播放器给出明确下载提示，不自动联网下载。目录说明和原视频哈希见 [exports/README.md](exports/README.md)。

视频文件就位后，直接用浏览器打开 `index.html` 即可播放。推荐从本包目录开启仅限本机的预览服务：

```bash
node serve.mjs 8787
```

访问 `http://127.0.0.1:8787/`。章节按钮可以定位片段，场景链接可以查看动画源码的本地播放。用 Ctrl+C 停止服务。

渲染需要已有 Node.js、Playwright / Playwright Core、Chromium / Chrome 和 FFmpeg；工具不会安装依赖或浏览器。默认抽八张代表帧，或制作 13.6–16.4 秒的通知衔接短片：

```bash
node render.mjs stills
node render.mjs short
```

需要指定已有依赖时，设置 `AGB_PLAYWRIGHT` 和 `AGB_CHROME`。输出只允许放在 `generated/`，已存在的输出不会覆盖。跨机器字体和浏览器差异可能改变画面；原成片仍为准确播放基准。原场景保留部分前次 seek 状态，新渲染器顺序计算未捕获的中间帧后再截图，不改原源码；完整动作检查仍以正常播放为准。

配乐源码期望字段 `dur`，原 cues 使用 `duration`；可选命令 `node render.mjs score` 只在新生成的输入 JSON 中适配字段，原源码、cues 和 WAV 不变。此步骤还需要已有 Python 3、NumPy。日常播放与视频渲染直接用包内原 WAV。
