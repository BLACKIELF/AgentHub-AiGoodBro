# apple-video-design 使用说明

本目录是可复用的产品视频规则包，覆盖原创制作、参考复刻、多语言文字适配、运动学习、音画检查和可复现交付。规则适用于不同品牌、语言、画幅与制作工具；“Apple 风格”仅描述创作方向，本包不代表 Apple 官方、授权或认证。

## 阅读入口

- [SKILL.md](SKILL.md)：通用规则与任务模式。
- [逐帧与节奏检查](references/fidelity.md)：精确复刻和视频差异检查。
- [多语言与文字适配](references/localization.md)：译文、动态文字和局部布局适配。
- [从源码验证运动规律](references/motion-learning.md)：测量、复用与限定函数重写。
- [compare_video.py](scripts/compare_video.py)：比较原生视频帧和时间戳的可选工具。
- [openai.yaml](agents/openai.yaml)：Codex Skill 的界面元数据。

以上链接均相对于当前目录；移动时保留整个目录结构。`SKILL.md` 与必要辅助文件保持源规则原文，单次项目制作说明和历史 QA 不在通用包中。

## 使用方式

可直接阅读并应用规则，也可将此目录作为 Codex Skill 的可选安装源。本包不会自动安装、同步或覆盖现用 Skill；选择安装或覆盖前，应检查同名规则、比较差异并取得相应授权。

逐帧比较工具依赖现有 Python 3、NumPy、FFmpeg 与 ffprobe。从本目录查看参数：

```bash
python3 scripts/compare_video.py --help
```

实际比较命令和结果解释见[逐帧与节奏检查](references/fidelity.md)。工具不会修改输入视频；报告输出须使用独立路径。像素比较不代替完整观看、听音和用户验收，也不证明素材使用权。
