# 从源码验证运动规律

先运行生成参考成片的确切入口。把界面几何、动画数据和运动函数分开测量：对象在原画布的位置，镜头关键点，进入与离开时刻，插值曲线，状态数值，音效起音。逐项记录来源；源码中的参数是本片事实，不是其他项目的默认值。

读字体声明还不够。确认浏览器实际使用的字体与字重，区分拉丁字形、中文回退和表情字形。无字形结果只表示该节点未得到测量，不能推断字体已经一致。把未受相机变换的基础几何与相机投影后的画面分别记录。

需要检验是否理解运动时，保持原素材和布局，单独重写一组明确的函数，例如关键点插值、标题显隐、圆环弧长或消息入场。在相同时间输入下，比较原函数与重写函数的数值、DOM 状态和原生无损画面。不要在不必要的框架迁移中混入更多变量，也不要把保留的原组件计入独立重写成果。

运动公式必须保留单位和定义域。拍数与秒的换算、入场动画按秒还是按拍、圆环画剩余额度还是已用额度、百分比小于 1 时的显示、弹簧是否越过终点、标题离场期间的模糊和缩放，都可能让静态落点相同而途中不同。检查速度曲线、状态切换帧与原有相机停驻期间接力的动作。

重写结果与原实现以相同输出帧编号对照，覆盖全部帧。保留浮点数差异和像素差异的原始数值；小差异不能写成全等，编码压缩后的相同也不能由浏览器中间帧直接推断。分别报告哪些函数重写、哪些部分复用、比较环境及仍缺失的测量。

运动学习与多语言适配是不同验证范围。语言替换、动态字符串覆盖和实测排版按 [多语言与文字适配](localization.md) 执行；其必要视觉差异不计为独立运动函数重写，也不能由运动数值相同推断像素相同。

最终导出的 MP4 另做完整解码、时间戳、音轨与播放检查。运动数值通过、像素近似、翻译完成和观看验收是不同结果。项目案例的原始测量与比较记录保存在项目 QA 目录；本参考正文不固定任何品牌、配色、字号、BPM 或时长。
