# 多语言与文字适配

用于保留原工程的镜头、布局关系和音画，把屏幕文字、动态消息、标题、字幕与片尾替换为目标语言。改语言不自动授权改时间线、产品事实或广告承诺。

## 建立覆盖清单

记录字符串的原文、译文、来源节点或数据键、出现时段和用途。范围应覆盖标题、按钮、账号状态、通知、消息、提示、图表单位、伪元素、Canvas 文字及用户指定片尾；按工程实际内容检查，不为不存在的层制造任务。

区分静态 DOM 和渲染函数每帧重写的文字。只替换 HTML 初始文字可能被后续 `frame(t)`、模板或状态更新写回；优先改实际数据源或渲染入口，让直接 seek 和连续渲染都获得正确语言。对用户删掉的句子核对所有实际输出位置及配套文案。

译文保留人称、功能含义、否定、程度、金额、单位、时间周期和链接；优先自然、简洁的表达，不为了简短丢失限定条件。用户给了确切译文则以它为准。保留产品名、邮箱、URL 或批准的专名时明确它们是例外。

## 宽度与几何

1. 等真实字体与所需字重加载后，测量文本宽度、行盒、按钮和父容器；同时看原生尺寸画面。字符数量不表示可用宽度。
2. 先选含义完整且简洁的译文；仍放不下时，只在受影响元素局部调整换行、字号、行高、字距或内边距，保持视觉层级和可读性，不默认缩小整个界面。
3. 依赖名字长度定位的徽标、图标与数值改用真实宽度、组件锚点或已有布局关系。检查最长内容及动画中的中间位置，不只检查初始落点。
4. 对经过相机变换的元素，同时检查基础几何与投影后的画面。必要的局部布局可以调整对象相对位置，并记录其视觉差异；保留原显隐时刻、缓动和运动机制，不借文字适配重写整体相机或时间线。检查适配后是否遮住邻接控件或把文本推离安全区。

仅当用户允许改节奏时，才重新分配文字展示时间并同步调整声音。语言更换、字体适配和原片局部修复属于实际视觉差异，不宣称与原语言画面像素全等。

## 实现与重复运行

复用已有本地化表或项目工具。简单工程可以使用受控替换，但记录预期命中次数；必需来源缺失或命中数量异常应定位，不能静默跳过。避免跨无关标记的宽泛替换，避免把代码变量、资源名或 URL 一并翻译。

重建脚本应从固定基准重新生成，或明确只对指定版本执行；同一输入重复运行应稳定。区分源文件、生成文件、后续手工适配，写明生成步骤和覆盖关系。若脚本前后需要两次本地化或特殊顺序，应在复现说明中明确，不能靠操作者记得当时操作。

搜索残留源语言作为辅助线索，维护允许保留清单。源语言文字为零并不证明翻译正确；映射条目数量也不证明屏幕覆盖完整。查看每个实际文字事件及动态状态，用短句含义、上下文和实际输出校验。

## 分别验证时间、内容与声音

对照同一时间输入下的相机、标题显隐、消息进出、图表值和相关控件状态；记录比较字段、逐帧范围和最大差异。保留未适配区域的对照以及适配区域的布局检查。只比一组运动字段不能证明所有 DOM 和画面相同。

检查每个镜头进入、运动中、落点和离开，以及最长文字、动态重写和最后一帧。先用局部帧发现溢出，最终检查完整编码文件和正常速度播放，不能只验证网页。

原音轨保持不变时，核对复用来源、音频起点与实际样本；需要声音同一性的证据时采用一致解码参数比较 PCM，并报告采样率、声道、样本数及差异。PCM 相同只证明该比较条件下的声音数据相同，不证明听感、动作同步或播放设备体验合格。

本地化交付附译文映射、必要布局变化、源码生成顺序和检查范围。所有译文完成、所有运动字段一致、最终媒体可播放与用户认可分别记录。

## 价格与配套文案

仅在用户要求列价或换算时使用。按指定来源读取可见售价，区分供货价与客户价，模糊或缺失的字段不猜。保留套餐名与计费周期；月价、数月套餐总价和一次性服务不能混写。

币种换算使用可核实的汇率及日期，保留原币金额，明确换算数值为约价，四舍五入规则一致。使用交叉汇率时先核实基准币种和乘除方向；不要把暂时汇率写成 Skill 常数。促销句忠实表达“超值、低价”等原意，不无依据升级为“全球最低、无人能比”或增加优惠条件。

配套文案与检查说明分开，用户删除的优惠句同步从当前稿和待交付包移除。用户要求只翻译上一条时，不自行改成引用帖，不增加对方没有给出的链接、标签或承诺；具体平台操作使用当时可用的发布流程。
