# 逐帧与节奏检查

## 锁定基准

记录参考视频和实际生成它的源码入口、素材与字体、画布、DPR、帧率、时长、音轨起点及必要随机种子。源码版本名不证明成片由它生成；先实际跑出基准。已有可用工程沿用其渲染器，不先做框架迁移。

把用户允许改变的项目列清楚：文字、头像、比例、原有缺陷修复或明确允许的时间线改编。其他参数跟随基准。用户取消长度限制后，不继续沿用旧的补时方案。

精确复刻的默认时间关系为 `source_time(t) = t`。未经用户要求插入常量区间，会使参考仍在运动时输出冻结；只在冻结后挑取对应截图，依然可能得到极低像素差异，不能证明时间线一致。

建立简短镜头表即可：镜头、起止帧、主体/相机、进入与离开动作、文字出现帧、状态变化帧、音效起音帧。逐镜核对起止和连接；不要把原创时的镜头表反过来覆盖参考片。

## 逐帧对比工具

使用随包脚本，依赖现有 Python 3、NumPy、FFmpeg 和 ffprobe：

```bash
python3 scripts/compare_video.py \
  --reference /absolute/path/reference.mp4 \
  --candidate /absolute/path/candidate.mp4 \
  --report /absolute/path/project/qa/frame-comparison.json
```

从 Skill 根目录运行上述相对入口，或使用脚本绝对路径。输出 JSON 概要与同名 CSV；不修改视频、不自动对齐、不缩图、不补帧。

报告与标准输出只保留输入角色和文件名标签，不写入机器目录。JSON、CSV 输出不得通过原路径、软链接或硬链接指向参考视频、候选视频、遮罩输入或彼此；写入前还核对实际文件标识。安全检查拒绝时返回退出码 2 与 `report_written: false`，不会为记录错误而写入冲突输出。

工具先核对原生尺寸、帧率、每帧时间戳和时长。它们不一致时返回退出码 2，说明无法按原时间线逐帧对照。可按实际 PTS 进行后续诊断，但不可偷偷调速、裁剪或对齐来让它通过。

条件一致后，以输出帧编号同步解码 RGB，每帧记录全画面平均像素差、对照区域平均差、变化像素比例及两边相邻帧的变化量。默认像素容差为 0；参考与候选使用不同有损编码时通常不会像素全等。此时优先导出同一渲染环境的无损中间片再对比，并另外验收最终有损成片。

`--mae-tolerance` 可以显式记录已说明的编码容差，不得把容差内的通过描述成逐像素完全相同。默认的变化像素阈值为 8/255，只用于报告显著差异比例，不放宽全等判定。

新增冻结诊断使用对照区域的相邻帧平均差，默认将候选变化不超过 0.05/255、参考变化超过 0.20/255 且持续至少 0.2 秒的区间列出。阈值与区间都会写入报告。这是线索：缓慢运动、局部静止、声音与审美节奏仍需人工查看，不因“未检出”就宣称没有停顿。

结果含义：

- 退出码 0：在报告记录的时间线、遮罩和容差下，全部比较帧通过像素判定，未检出新增冻结。
- 退出码 1：比较已完成，存在像素差异或新增冻结线索。
- 退出码 2：输入、解码或时间线条件不满足，未完成有效的整片逐帧比较。

## 已授权替换的遮罩

可增加 `--masks /absolute/path/masks.json`。每个矩形必须给出具体原因及作用时间，坐标基于原生画布：

```json
[
  {
    "x": 48,
    "y": 32,
    "width": 80,
    "height": 80,
    "start": 0,
    "end": 5,
    "reason": "用户要求替换此时段的品牌头像"
  }
]
```

这些数值只是 JSON 格式示例，不是设计默认值。移动头像需使用逐段追踪矩形或更精确的项目工具，不能用宽条遮住整条移动路径。工具同时保留未遮罩全画面差异与遮罩覆盖比例；遮罩把整幅画面覆盖时拒绝通过。

不要添加字幕、水印、角标之后再遮掉所有顶部或底部以宣称高精度。品牌适配区也须另行查看素材正确性、边缘、裁切、字号和运动。

## 声音与观看

画面对比脚本不判断声音。记录音乐拍点、重要起音、音效与动作发生帧；完整听看片，核对音效前置、尾音、静音和结尾。音视频 start_time 都为 0 只能证明容器起点一致，不能证明动作与音效同步。

检查 100% 尺寸的关键帧和过渡过程，重点查看中文字形、镜头边缘、材质、图表弧长与数值、头像形态、弹层及水印遮挡。至少覆盖每个镜头的进入、运动中、落点和离开，最终帧也单独查看。联系表用于定位，完整播放用于判断节奏。

出现短暂越界、放大裁切或遮挡时，先与参考同一时刻对照，区分参考本来的入场效果和候选新增缺陷；不要把有意的动态效果按静态页面溢出统一修掉。替换文案新增的重叠、裁切或不可读仍须局部修复，并记录差异。

状态比较只支持实际记录的字段。明确列出相机、标题、消息、圆环等字段及逐帧覆盖范围；没有采集的 DOM、滤镜、字体或局部动画不能据此宣称相同。最终 MP4 的 PTS、解码与播放检查仍须单独完成。

像素相等、时间线相等、音画同步、技术合格和用户认可分别报告，不互相替代。
