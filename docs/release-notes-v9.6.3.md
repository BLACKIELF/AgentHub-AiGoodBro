# AiGoodBro 9.6.3 / 0919v2

本机安装日期：2026-09-20

## 相较 0919v1 的变化

- 用量图表嵌入层不再拥有自己的滚动条。WKWebView 的滚轮事件转交首页外层 SwiftUI `ScrollView`，网页通过 `chartSize` 消息上报实际内容高度。
- 90 天概览改为紧凑的 7 行日历热力图与主要宽度趋势图；小窗口切换为上下布局，并避免内层横向滚动。
- 选中日期详情移到趋势图下方，绑定真实统计数据，展示总 Token、各工具占比/条形图、SVG 构成图和图例；热力图点击及 Enter/Space 键选择都会更新。
- 首页重置消息保留窄概要。历史消息在当前首页内联展开/收起，不再打开独立 `NSPanel`。
- 首页当前公告过滤为当前时间向前 30 天、时间不在未来且通过 `PublicResetAnnouncement` 验证的记录；没有时显示“暂无近期可验证的新公告”。公告时间统一至少显示 `yyyy-MM-dd HH:mm`，旧年份只留在历史记录。
- 版本号更新为 `CFBundleShortVersionString 9.6.3`、`CFBundleVersion 52`、`CodexAccountManagerNextReleaseName 0919v2`。

## 数据与语义边界

图表仍使用运行时真实用量快照；视觉方案中的示例数字和趋势数组没有写入生产资源。公开重置公告仍不表示个人额度已到账，账号页官方读取和可用重置卡状态仍是唯一个人依据。HomeSkillShelf、账号、登录、Windows、调度和 Token 采集路径未纳入本次修改范围。

## 验收边界

最终构建通过 32/32 Swift 自测、前端契约测试、运行时资源校验和严格签名校验。已覆盖安装到 `/Applications/AiGoodBro.app`，安装版与验收构建的可执行文件及图表资源哈希一致。真实界面已确认：首页消息为顶部窄概要、三个 Skill 位于账号前、无独立消息窗口；鼠标位于图表区域滚动时由首页外层滚动容器接管。
