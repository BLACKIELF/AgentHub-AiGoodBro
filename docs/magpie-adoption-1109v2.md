## 采用边界

参考 [Magpie 固定版本 README](https://github.com/yetone/magpie/blob/bceeabd93a9ea55c925efe4ecaddd31829c3aa2f/README.md) 的模型搜索、常用列表、Profiles、隐私 Try it 和只读 CLI 思路，按本项目现有结构独立实现。

本轮没有宣称完整复制 Magpie：任意服务商密钥导入、跨工具全局配置切换、透明请求遮罩/还原、Bun 插件运行时、远程同步与意图路由均未接入。这些会增加常驻组件、外部配置写入或请求处理范围；当前已核实的安全接入和原有功能保持。非 Codex 自动用卡仍需真实到期与兑换接口证据。

启动方案 JSON 是本软件的方案格式，不是 Magpie/CC Switch 服务商配置，也不导入登录态。离线脱敏规则不能识别所有敏感信息，预览结果仍须用户检查；不下载 Magpie 可选的隐私模型。
