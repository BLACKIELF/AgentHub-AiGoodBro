# AiGoodBro v9.6.80 (130)

Release name: 1006v3

## 主要更新

- 修复主页与菜单栏累计 Token 不一致：总 Token 和估算成本共用同一份总计快照，暂不可用时明确显示未知。
- 修复辅助进程关闭管道可能导致应用异常退出的问题。
- 重置卡临期自动使用支持桌面账号的同身份独立入口。逐账号自选，默认关闭、提前 30 分钟，帮助避免忘记使用造成到期浪费；账号忙碌、身份或任务状态不明时暂停。点击卡片上的重置卡数量／到期时间可打开设置。
- 原生更新弹窗展示版本和更新内容；点击下载可查看进度、取消、重试，校验后打开安装包，由用户完成覆盖安装。
- 新装／覆盖安装选择新用户或老用户，老用户聚焦微信、飞书与新设置；保留美化的设置弹窗和新功能提醒。
- 选择性修复 Token Monitor 文件监听、大会话读取和导出文本过滤，保留原有主题、反代勾选同步、⌘I 侧栏和 Pro／Plus 额度显示。

- 本次提供 macOS 13+ Apple Silicon ARM64 安装包；升级前请结束任务并正常退出旧版。安装说明及运行边界见[完整发布记录](https://github.com/BLACKIELF/AgentHub-AiGoodBro/blob/v9.6.80/docs/release-notes-v9.6.80.md)。

## 验证与运行边界

本次仅发布 macOS 13+ Apple Silicon ARM64；未构建 Intel 或 Windows 安装包。Token Monitor 继续锁定 0.62.0，附选择性回移；未升级完整 0.66、历史计价、压缩 DSH 或超大 custom-root polling。

完整 ARM64 发布构建与 35 组应用自测、114 项重置卡自动使用断言、181 项安装引导断言、26 项 Token Monitor 回移测试、39 项运行时打包测试通过；包内 Electron 的累计统计与大会话夹具通过。DMG 只读挂载、ZIP 解压完整文件树及严格递归签名检查通过。未以真实账号验证自动兑换、微信／飞书送达、全局快捷键与完整下载后安装生命周期；不因查看设置自动启用功能。安装前先结束任务并正常退出旧版，保留应用和本机数据备份。

签名：本地 ad-hoc 完整性签名，未 Apple 公证。
