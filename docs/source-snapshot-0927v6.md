# AiGoodBro 2.0 主线更新 · 0927v6

本次将当前开发成果整合为 `main` 上的 AiGoodBro 2.0 大版本。产品版本为 2.0，内部构建版本沿用 9.6.18 (67)，保持既有版本比较与升级顺序；不把内部 9.x 改成会被旧更新器视为降级的 2.x。已安装并用于截图的版本仍为 9.6.17 (66) / 0927v5。没有生成安装包、Tag 或 Release。

## 已纳入

- Token Monitor v0.62.0 固定版本的桌面界面整合：用量看板、菜单浮窗、右侧停靠栏、字体、Agent 图标与玻璃效果；AiGoodBro 品牌、统一入口及单 Dock 图标。上游版权和许可来源保留。
- 公开重置预告与完成公告、当天消息高亮、飞书新预告去重推送。
- Kimi 等本机 CLI 额度读取与刷新修复；缺少官方会话或额度接口的来源仍显示真实限制。
- 用量详情默认折叠，中英文界面与说明；[最新实机截图](images/0927v6/README.md)。
- Pro / Prolite 官方未提供五小时窗口时按真实周额度判断；一次性内存模拟低额度入口，不改写官方额度数据。

## 验证范围

- 当前源码 252 个 Swift 文件逐文件语法检查通过。
- 已安装的 9.6.17 (66) 通过自动切换策略、切号安全、会话链接、任务运行态四项纯自测；这不是当前 9.6.18 二进制的运行测试。
- 新增 Desktop IPC 传输独立 typecheck 通过，真实只读验证能够读取当前 Desktop 任务及轮次。
- 当前桌面适配层 6 项 Node 测试通过；新增文档本地链接和暂存区空白检查通过。
- Swift 格式检查通过；CI 增加官方固定运行时的 SHA-256 校验与只读挂载，让干净环境执行原有完整构建和测试。
- 本次没有暂停任务、切换真实账号、发送续做请求或通知。

## 仍在进行

真实“模拟低额度 → 暂停运行任务 → 切到有额度账号 → 继续原任务”尚未验收。当前 Desktop 未提供旧版共享服务连接；新增本机 IPC 传输尚未接入完整生产链，完整活动任务枚举仍需解决。单个任务的中断回执不能证明全部子任务停止，缺失证据时必须停止切换。

9.6.18 还需冻结后重新完整构建、相关回归测试与覆盖安装。Windows、本机 WidgetKit、Antigravity OAuth 和后续主题仍按[既有集成记录](ai-goodbro-2.0-0927v5.md)的边界处理，不将源码存在写成运行验收通过。
