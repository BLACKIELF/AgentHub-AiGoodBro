# AiGoodBro 2.5.2（153）预发布

Release name: 1023v1

发布日期：2026-10-23。平台：macOS Apple Silicon（arm64）。保留既有稳定版，本次不替换稳定版下载。

## 主要更新

- 反代面板采用紧凑布局，详情与队列共用滚动区，直接显示“优先／最后使用”；运行中的顺序调整对新请求生效。
- Pro 支持 5／10／20／25 倍手动标签，统一显示官方 7 天额度；Plus 保留双窗口，未知额度继续显示未知。
- 修复非 Codex 登录尝试的完成判断，以及账号池取消、重复授权和迟到回调的状态隔离。
- 首页汇总与趋势使用同一 Engine 快照；点击侧栏“今日”可打开主窗口。
- 保留固定反代入口、可选出口恢复、多平台独立账号池和飞书授权修复，CLIProxyAPI 固定为 8.0.38。

[完整说明与已知边界](https://github.com/BLACKIELF/AgentHub-AiGoodBro/blob/v2.5.2-1023v1/docs/release-notes-v2.5.2-1023v1.md)

- 构建完成，资源和严格递归签名检查通过；35 组原生自检通过，Carbon 系统热键集成子检查明确跳过。
- 40 张隔离原生反代预览覆盖中英文、深浅主题与窄窗口；代表图已查看。这些合成预览不代表安装版交互验收。

- 用户完成覆盖安装后，只读核对安装版为 2.5.2（153）/ 1023v1；2,186 项路径、类型、权限、文件内容与链接均匹配候选，三个核心二进制及严格递归签名检查通过。
- 已构建的 36 个源码变更在发布前与冻结输入逐项匹配；发布提交另更新两份 README、CHANGELOG 和本说明。生产源码、资源与安装包未因发布文档更新而改变。

- 本次未执行安装版完整交互、所有平台真实登录/推理、长期运行稳定性或故障节点恢复验收。隔离环境曾保存两个不同的 Antigravity 账号，不等于生产账号池与真实模型调用已验收。
