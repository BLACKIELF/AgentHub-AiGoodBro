# AiGoodBro 2.5.3（161）

Release name: 1028v1

版本日期：2026-10-28。macOS 面向 Apple Silicon（arm64）；Windows x86_64 独立封装，两个平台按各自已实现的功能验收。

## 本次变化

- **主页统计与时长**：统一使用 Token Monitor 的汇总与历史数据；修复合法上游记录导致整组历史无法展示的问题。同来源刷新期间保留并标明上一份图表，切换来源后清除旧图，防止迟到结果覆盖新来源。
- **用量解析**：修复 Codex 压缩记录、结束事件、大型归档漏计、Qwen 重复计数和 Cursor 重叠快照重复统计。Token Monitor 保持 0.68.0 界面基线，仅回移已审核的修复；估算成本不等于供应商账单。
- **反代停止与退出**：停止、登记清理与诊断写入避免长时间占用主界面；短暂控制忙碌有界重试，未知占用保持保护。用户二次确认“强制退出”后，终止应用持有的辅助进程，设置 5 秒退出上限；取消确认不影响当前任务。
- **可选故障恢复**：手动开启后，内部故障先核对并清理原运行实例，再沿用固定端口和持久密钥重启。10 分钟内最多尝试 3 次，手动停止会取消恢复，已发送的模型请求不自动重放。
- **上游适配**：流式响应在开始文字或工具输出前缓冲元数据；Claude 限流显示并遵循服务端有效重试时间，输出上限返回截断状态；Cursor 未确认的套餐额度保持未知。
- **已有定制**：保留账号参与、优先、最后使用、显示顺序、点数、Plus 5 小时上限、配置和外观；收录此前的消息凭据恢复修复。软件内更新介绍同步。

## Windows 范围

Windows 2.5.3 提供本地工作台、已关联账号目录、手动官方额度读取，以及按工作目录和模型打开隔离终端、停止本应用启动的终端进程树。它没有 macOS 的全部反代、通知和 Token Monitor 集成功能，也不提供受管账号登录或全局账号切换。详情见 [Windows 使用与构建说明](../windows/README.md)。

Windows 安装包由独立 Windows 构建流程生成 MSI 与 NSIS EXE，运行原生编译、测试、界面回归和冷启动检查；不使用 macOS 上的交叉测试替代 Windows 验收。

## 验证与边界

本次发布前已有隔离测试覆盖历史统计、来源切换、反代停止清理、自动恢复与确认强退。软件的完整构建、签名、包内容、校验值和 Windows 原生构建结果，将在包验收完成后补充到本说明与 GitHub Release。

- 当前运行的安装版不会由打包或上传操作自动替换；没有执行真实账号切换、额度消耗、通知发送或生产反代重启。
- 历史红色状态与 503 的底层现场原因尚未完全确定；隔离测试通过不等于所有真实网络故障或长期运行问题已经解决。
- “强制退出”可能中断正在回复的任务；确认框实机交互、全部辅助进程后代和退出后真实租约恢复不作为本次已完成的生产验收。
- macOS 包不提供 Apple 公证，Windows 包不提供 Authenticode 签名；系统可能要求用户确认来源。已有账号和配置不随安装包分发。
- 不提供本次 Intel Mac 安装包。Windows 与 macOS 的功能范围分别说明，不以版本号相同表示功能对齐。

## 升级

先完成当前任务并正常停止反代、退出旧 App，保留旧版本和配置备份后再覆盖安装。macOS 升级后核对 **2.5.3（161）/ 1028v1**；Windows 安装后核对 **2.5.3**。历史 Release 保留，可按各平台说明回退。

安装包以本次 GitHub Release 中的独立校验文件为准；不将源码 ZIP 当作可安装程序。
