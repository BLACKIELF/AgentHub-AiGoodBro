# AiGoodBro 9.6.6 (55) · 0922v1

相较 9.6.5 (54) / 0921v2，本轮修复首页内容重叠，补齐分区折叠、弹窗退出、账号引导与额度信息，并压缩无用途的留白。保留此前未提交功能，没有创建提交、标签或公开发布。

## 修改意见与实现

| 用户意见 | 本版处理 |
| --- | --- |
| 首页“乱码”、消息互相遮挡 | 修复日历布局按四个子视图测量、实际只有三个导致高度为零的问题；非预期数量也逐项布局。 |
| 首页各分类独立折叠 | 重置消息、AiGoodBro 消息、推荐 Skills 与应用、已登录账号、Token 用量和维护提示分别记住展开状态。 |
| 留白合理利用，保持美感 | 日历与当天公告、个人重置时间并排；卡片只在同一行对齐，移除身份与额度间的弹性空白；四项推荐按四列或两列呈现，避免三加一。 |
| 模型与调度默认展开 | 保持默认展开，常用操作和模型设置集中排列。 |
| 添加界面能退出 | 添加 Agent 的标题与关闭按钮固定在顶部，完成固定在底部，长列表独立滚动，支持 Esc。 |
| 引导重点讲清 Codex 账号 | 首屏说明添加、官方设备码授权、返回确认额度三步；新账号和原账号重新登录分别提供入口。登录结束清理等待状态，身份存在但额度未验证时显示待确认。 |
| 直接显示美元、点数 | 分开标注美元与点数；缺失值显示 —，不从点数推算美元，不将未知显示为零。 |
| 其他 CLI 查看消耗、剩余与重置 | 有官方窗口数据时分别显示已用、剩余、重置；保留小数精度，避免互补值合计 101%；缺失窗口或重置时间明确显示暂不可确认。 |
| 全面检查交互和错误 | 同时修复日历显示三条却按五条计算剩余数量的问题，以及引导中 Codex 已验证按钮文案与操作不一致的问题。 |

## 数据能力边界

本版沿用各 CLI 已有的官方读取渠道，没有为不提供额度的渠道编造金额或重置时间。真实账号重新登录、额度消费、重置卡兑换、账号切换和通知投递没有作为验收动作。

Codex 的官方 Credits 与美元钱包属于不同余额；当前账号额度返回值未提供可验证的美元余额，因此美元显示 —。参考 [OpenAI Credits 说明](https://help.openai.com/en/articles/12642688-using-credits-for-flexible-usage-in-chatgpt-personal-plans) 与 [官方账号额度结构](https://github.com/openai/codex/blob/main/codex-rs/app-server-protocol/schema/json/v2/GetAccountRateLimitsResponse.json)。
