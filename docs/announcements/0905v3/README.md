## 历史使用方式（请勿沿用旧配图）

- 小红书使用标题与正文，去掉 Markdown 标题符号即可；按推荐顺序上传原始 PNG，不用把索引说明一起发出去。
- 公众号约 1600 个汉字，预计 5–7 分钟。将正文导入编辑器，再上传对应原图；相对图片链接不会自动变成公众号托管图片。
- X 单条与串帖按保守字符权重检查均小于 280。最终计数和可发布状态仍以 X 编辑器为准。串帖最后一条带完整 GitHub 地址与 Agent 指令；单条短推本身也包含这两项。
- 所有安装指令都要求先查已有版本、备份后原位升级、保留账号数据与当前登录。不要求读者提供密码或凭据。
- 小红书含标题、标签、链接、空格与换行共 971 个 Unicode 字符，低于本次 1000 字约束；平台显示计数可能采用不同口径。
- 小红书外链按维护者明确要求保留。如平台编辑器提示限制，以其提示为准；本轮没有自动发帖。
