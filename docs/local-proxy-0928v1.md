## 队列行为

- 同一额度档内优先账号在前，同组按保存顺序调用；当前桌面身份的独立托管副本在订阅与点数阶段内最后，即使设置了优先。遇到登录失效、占用或短暂故障时，按相应状态跳过或冷却；整个队列不可用时返回错误。
- 每次请求前校验最新额度、账号身份及凭据有效期。正在派单的账号不会同时交给代理；代理请求占用也会挡住新的派单。空闲账号仍可参与原有调度。
- 凭据读取与额度刷新共用安全锁；请求最多等待 12 秒，持续占用显示“凭据读取中”。原有两秒等待会在短时刷新中误报任务忙碌，已补充隔离回归验证。
- 原有“参与调度 / 优先调度”设置不被改写。反代的“参与调用 / 优先调用”单独保存。76 允许运行中修改顺序和优先级；下一个请求读取新顺序，当前请求及其重试使用原顺序。87 起可在运行中调整已登记账号的参与开关：关闭后只影响新请求，已有请求保留原账号快照直至完成；不必等待其他账号空闲。新建账号需要下一次正常启动后登记。
- 系统账号目录不作为执行目录；经用户选择的同身份独立托管副本可以作为最后候选，仍需完整身份与额度核验。Pro 官方未返回短窗口时，按有效周额度判断；未开启点数接续时仍要求明确的零额外余额证据，缺失信息不猜测。
- “点数接续”默认关闭。开启后先使用全部参与账号的可用订阅额度，再依次选择点数高于第一档、第二档底线的账号；桌面账号在订阅和点数阶段内最后考虑。忙碌、冷却、未知或过期不代表订阅用尽，仍有订阅额度时不进入点数阶段。默认底线为 2000 / 1500 点，可在反代设置修改并保存；第一档必须高于第二档，第二档不低于 0，停止代理后才能修改。
- 点数等于或低于本档底线不再获准发送新请求；此前每次请求完成后刷新余额，后续点数请求必须取得结算后的新快照。过期、未知、无穷或格式异常的余额均不放行。单次请求结算可能跨过底线，因此这是请求之间的轮换条件，不是服务端硬性消费限额。
- 已向客户端输出流式内容后发生错误，不跨账号重放，避免重复执行工具。400 请求错误不换号重试；401 标记登录失效，429 进入额度冷却，临时错误单独标记。

## 客户端与凭据

服务只监听本机随机端口，使用每次启动独立生成的访问密钥；支持 Responses、Responses compact 和模型列表接口。复制的连接配置用于支持自定义地址的客户端。Codex CLI 需显式选择自定义 provider，不能仅凭环境变量断定已经走代理；具体配置见[组件说明](../Companion/LocalProxy/README.md)。

“接入桌面”要求先退出 Codex，再从 AiGoodBro 重新打开。它为本次启动提供 app-server 包装入口，使用官方支持的 `openai_base_url` 仅覆盖本次模型请求地址，在新建、恢复和分支任务时保留 `openai` 标识；历史列表保留原任务。模型、推理强度、工具及其他请求字段沿用对话设置，不改系统认证或全局配置。已有进程不会采用新的启动参数，运行中的任务也不会自动改路由。代理关闭后需要正常重开 Codex；代理重启后需要从该按钮重新接入。旧任务需在新版适配器中恢复一次以纠正旧的 provider 选择，历史创建标识不被重写。桌面身份、云端功能与本地模型请求路由是不同状态。

每次运行的桌面连接文件仅含随机本地访问密钥及启动元数据，位于当前用户拥有的 0700 目录，文件权限为 0600，拒绝符号链接和异常字段；停止代理时删除。OAuth 凭据不进入该文件。

模型与推理强度由每个客户端请求指定，代理不会套用账号保存的模型偏好。当前模型目录来自 AiGoodBro 支持的 Codex 模型；未支持的模型会明确失败，不静默改用其他模型。

上游连接读取系统手动 HTTPS / SOCKS 代理，保留目的地绕过规则，不继承进程中的 API 地址覆盖。PAC/WPAD、需认证的代理及无效端口会在启动时说明不支持。本机验证中直连超时，而现有系统代理能连接上游；此适配未修改系统网络设置。

Go helper 不保留 OAuth 刷新令牌，不执行登录、刷新或切换桌面身份。每个请求通过原生宿主获取受占用保护的短期 access token；退出和异常后，仅在确认子进程终止后回收占用。冷却与队列设置保存在独立的本地目录。

未开启点数接续时，额度准入基于已核验的订阅窗口；开启后才按已保存底线使用点数。不会自动充值、购买或使用重置卡。

## 9.6.24 修复与验证

- 原 32 MiB HTTP 上限会阻断图片较多的长任务。按用户要求取消本地请求大小上限，同时取消 Desktop JSONL 原 64 MiB 限制；官方服务自身限制仍由服务返回。
- 原自定义 provider 会改变桌面账号模式，并把失效标识存入任务。现在保留官方 provider，只在进程参数中覆盖模型地址。中间网关只读核验当前文件型登录令牌，再替换为本次反代密钥；桌面令牌与账号标识不发给上游。文件型登录之外的凭据存储尚未支持，失败不降级放行。
- 原适配器删除 `CODEX_CLI_PATH`，会让官方插件回退到未签名 Node。现在传入原版 Codex 路径，官方 launcher 已验证选中 OpenAI 签名运行时；签名检查未修改。
- Go tests、race、vet 通过，包含 40 MiB 图片、40 MiB compact、65 MiB JSONL、认证刷新、错误凭据拒绝与身份头隔离。使用真实 Codex app-server、隔离假账号和本地服务的五轮测试通过旧 provider 恢复、工作区身份、普通 Codex 冷恢复及模型/强度保留；签名打包 helper 重测同样通过。
- 候选运行时资源、内嵌组件和 deep strict 签名通过。真实 Desktop 重连、原生工具接入和 WAICY 原任务仍待安装后验收，不把隔离验证说成已在当前对话生效。
