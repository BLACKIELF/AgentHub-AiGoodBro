# AiGoodBro 本地反代 · 0928v1

当前已安装的反代候选内部版本为 9.6.22 (72)。在 Codex 账号页点击“反代模式”，选择参与账号、优先账号及同组顺序，再点击“开启反代模式”。启动后可复制连接配置，或退出 Codex 再点击“接入桌面”。关闭面板保持运行，关闭反代或退出应用会停止 helper 并确认占用释放。重启应用不会自动开启反代。

## 个人使用与来源

本功能仅限个人使用。Tibo 在公开帖子中介绍了安装 CLIProxyAPI、连接账号、通过别名在 Claude Code 中调用 GPT 的步骤；原帖见 https://x.com/thsottiaux/status/2076119366647894371 。该帖子提供技术背景，不是本项目的官方授权。上游许可证继续适用。

## 队列行为

- 优先账号在前，同组按保存顺序调用。遇到额度耗尽、登录失效、占用或短暂故障时，按相应状态跳过或冷却；整个队列不可用时返回错误。
- 每次请求前校验最新额度、账号身份及凭据有效期。正在派单的账号不会同时交给代理；代理请求占用也会挡住新的派单。空闲账号仍可参与原有调度。
- 凭据读取与额度刷新共用安全锁；请求最多等待 12 秒，持续占用显示“凭据读取中”。原有两秒等待会在短时刷新中误报任务忙碌，已补充隔离回归验证。
- 原有“参与调度 / 优先调度”设置不被改写。反代的“参与调用 / 优先调用”单独保存；调整队列前先停止代理。
- 中枢系统账号及其同身份副本不进入代理池。Pro 官方未返回短窗口时，必须有有效周额度和明确的零额外余额证据；缺失信息显示未知。
- 已向客户端输出流式内容后发生错误，不跨账号重放，避免重复执行工具。400 请求错误不换号重试；401 标记登录失效，429 进入额度冷却，临时错误单独标记。

## 客户端与凭据

服务只监听本机随机端口，使用每次启动独立生成的访问密钥；支持 Responses、Responses compact 和模型列表接口。复制的连接配置用于支持自定义地址的客户端。Codex CLI 需显式选择自定义 provider，不能仅凭环境变量断定已经走代理；具体配置见[组件说明](../Companion/LocalProxy/README.md)。

“接入桌面”要求先退出 Codex，再从 AiGoodBro 重新打开。它为本次启动提供 app-server 包装入口，在新建、恢复和分支任务时选择本地 provider；历史列表保留原任务。模型、推理强度、工具及其他请求字段沿用对话设置，不改系统认证或全局配置。已有进程不会采用新的启动参数，运行中的任务也不会自动改路由。代理关闭或重启后，旧连接失效，需要再次退出 Codex 并从该按钮接入。桌面身份、云端功能与本地模型请求路由是不同状态。

每次运行的桌面连接文件仅含随机本地访问密钥及启动元数据，位于当前用户拥有的 0700 目录，文件权限为 0600，拒绝符号链接和异常字段；停止代理时删除。OAuth 凭据不进入该文件。

模型与推理强度由每个客户端请求指定，代理不会套用账号保存的模型偏好。当前模型目录来自 AiGoodBro 支持的 Codex 模型；未支持的模型会明确失败，不静默改用其他模型。

上游连接读取系统手动 HTTPS / SOCKS 代理，保留目的地绕过规则，不继承进程中的 API 地址覆盖。PAC/WPAD、需认证的代理及无效端口会在启动时说明不支持。本机验证中直连超时，而现有系统代理能连接上游；此适配未修改系统网络设置。

Go helper 不保留 OAuth 刷新令牌，不执行登录、刷新或切换桌面身份。每个请求通过原生宿主获取受占用保护的短期 access token；退出和异常后，仅在确认子进程终止后回收占用。冷却与队列设置保存在独立的本地目录。

额度准入基于已核验的订阅窗口，不以额外余额作为可用额度。请求可能在运行中跨越限额边界，因此不能将预检宣称为绝对零付费保证。

## 来源与构建

复用 [CLIProxyAPI v8.0.2](https://github.com/router-for-me/CLIProxyAPI/tree/v8.0.2)，固定提交 `4a2c81864f31f39308e946c4c65e72147855da6e`。使用其 SDK 调度、Codex 执行器及 Responses 处理器；不启动上游完整服务、管理接口、后台发现或 OAuth 刷新。桌面包装入口参考 [Hazmat 的 Codex Desktop 接入脚本](https://github.com/dredozubov/hazmat/blob/c112d222bb53e888dd17a8927927286792f7c20e/scripts/check-codex-desktop-attach-smoke.sh)，未集成其沙箱或服务。两者的 MIT 许可证与来源随包保留。源码构建需要 Go 1.26+，安装后的 helper 为独立原生程序。

- 引擎覆盖按顺序切换、限额冷却、取消释放、并发互斥、流式失败不重放、模糊状态停止，以及 compact 请求的先占用后发送。

- 真实 Codex app-server 配合本地模拟服务完成新任务、历史列表、关闭后恢复和两轮请求；模型与强度保留。该测试不使用真实账号，不能替代完整 Desktop 界面验收。
