## 结论

当前 Windows 实现是本地只读 Dashboard，不是完整的账号管理器。它已有 transcript/state 读取、官方额度旁路、任务/项目/Skills/Leadership 展示、设置、主题和托盘刷新；没有 managed profile store、登录导入、手动或自动切号、跨进程占用、通知、暖号、调度和重置卡执行链。

Windows 端缺失的 macOS 对齐能力可以在 `windows/` 内用 Rust、Tauri 和 React 原生实现，属于允许的迁移工作，不因 Windows 还没有该功能而被视为“禁止开发新功能”。限制是：Windows PR 不得为了迁移反向修改 macOS 行为；真正新增且两端都没有的产品语义仍需先单独确认。

## 固定基线与协作方式

- 可读取的稳定源码基线是 `V1.0`：macOS 9.6.1（50），提交 `517f2daeccca54fe9c388660c52889aef48f54dd`。
- 9.6.2（51）的身份、防重复与暖号安全修复作为必须满足的行为增量；在其源码正式进入主干前，不把本机未发布实现当作朋友需要猜测的移动目标。
- Windows 实现主责交给具备 Windows 真机环境的贡献者；仓库维护方负责功能契约、安全不变量、范围确认、代码审查和主干集成。
- P0/P1 完成前暂停新增需要双端同步的产品功能。macOS 紧急安全修复可以继续，但必须同步更新本路线图的行为增量；纯 macOS 外观改动不阻塞 Windows。
- 每个 PR 只完成一个可独立验收的纵向切片；双方不在同一功能分支或同一组文件上并行实现。

## 实施顺序

### P0 · 主干与开发基线

1. 处理 PR #5、#6；PR #7 如被 #5 覆盖则关闭而不重复合并。
2. 单独合入 `.gitattributes`，不执行全仓 renormalize。
3. 记录真实产品名、版本、bundle 标识和当前命令面；明确 Windows 仍是 read-only Dashboard。
4. 为每个阶段建立合成 fixture、Rust 单元测试、Web 契约测试和 Windows 真机验收入口。

### P1 · 账号核心与手动切换

1. managed profile 数据模型与原子存储；凭据不进入日志、WebView、fixture 或 Git。
2. 登录新账号、关联已有 Codex home、取消登录和移除账号。
3. 手动切换事务：准备、占用、写入、启动/重启、最终身份验证、成功提交或回滚。
4. 多账号列表、当前身份、官方额度和明确的失败恢复 UI。

P1 是“Windows 账号管理器成立”的最低门槛。完成前不做自动切换、暖号或通知扩展。

### P2 · 自动切换与并发安全

1. 跨进程共享占用和单实例写入边界。
2. 候选账号门禁、额度新鲜度、退出/启动证据、取消与超时。
3. 请求代际与迟到回调隔离；成功不能被旧失败降级，失败不能污染新身份。
4. 崩溃恢复、占用清理和人工恢复入口。

### P3 · 调度、CLI 与消息

1. 原生终端和隔离 CLI 入口，再接调度参与/优先级/时段。
2. 任务、切换、额度与完成事件的系统通知。
3. 飞书、企业微信、Telegram 作为显式开启的外部通道；凭据使用 Windows 安全存储。

### P4 · Reset、暖号与高风险动作

1. Reset 公告与本机提醒先只读接入。
2. 重置卡和暖号必须复用账号身份、共享占用、额度新鲜度和幂等边界。
3. 网络结果模糊时保持 pending/人工处理，不以 reset 时间或超时为自动重发许可。

### P5 · 分发

完成 Windows 安装、升级、回退、代码签名、更新检查和真实机器发布验收，再声明 Windows 完整版本可用。

## 不可削弱的安全不变量

- account ID 优先于邮箱匹配；无法验证身份时停止写入与切换。
- 配置、账号状态和切换结果使用原子写入；保存失败不能显示成功。
- 同一账号/同一系统身份的敏感动作共用跨进程占用，进程退出不自动等于动作失败。
- 异步结果必须匹配请求 ID、来源身份和当前代际；迟到回调不得覆盖新状态。
- 模糊网络失败、进程超时和未知额度都必须 fail closed；未知不等于 0，也不等于成功。
- 测试只使用合成账号和隔离目录；真实账号操作、安装、签名和发布另行授权。

## 每个 PR 的交接格式

PR 说明必须写明：基线提交、一个纵向目标、未实现项、状态/存储变化、失败恢复方式、合成测试结果和 Windows 真机结果。维护方先核对契约与安全不变量，再按文档、Web、Rust/Tauri、原生行为四层验收，不以 macOS 测试代替 Windows 证据。
