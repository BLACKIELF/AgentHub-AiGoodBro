# AiGoodBro 2.0 · 0927v3

相较 [0927v2](ai-goodbro-2.0-0927v2.md)，本次补齐用户明确指定 20 倍 Pro 后的单次“暂停 → 切号 → 继续原任务”。内部版本为 9.6.15（64），已于 2026-09-27 09:35 覆盖安装。

## 范围

- 保留已有 1% 自动切换与账号事务；单次操作显式指定目标，只对本次请求使用官方已返回的周额度，不改变全局开关或账号参与偏好。
- 官方未报告的五小时窗口仍显示未知；已报告但耗尽的窗口不放行。身份、额度新鲜度、占用、暂停确认、历史核验、回滚和防重复续做继续生效。
- 原版用量浮窗、字体、Agent 图标、玻璃与右缘 Dock 沿用 0927v2；产品入口使用 AiGoodBro 官网和 GitHub 主页。上游接口和许可保留原始来源。

## 当前验证事实

单次请求在桌面操作前持久记录 UUID，重启重放同一编号会被拒绝；周额度规则与目标身份绑定保存。只有本次已确认成功的事务能自动续做，重启应用不会自行继续任务。桌面切换沿用原有额度判断，不额外套用独立 CLI 派单的“点数余额必须为零”规则；未启用付费回退或购买。

续接时只读核对发现，系统实际登录身份已与用户指定的 20 倍 Pro 一致，启动和监控也指向该账号；没有待处理切换事务。此结论来自凭据身份一致性核对，不仅是界面套餐标签。当前账号不需要重复切换，未擅自退回另一账号制造测试条件。

用户随后明确选择“保持当前 20 倍，完成修复和隔离测试”。本次按此选择保留登录，不中断真实任务或执行往返切换；不同真实账号之间的完整流程仍未经本轮实测。

CLT 26.5 全源编译通过，编译期间所有 Swift 源码摘要未变。7 组相关原生自检通过：自动切换、账号事务、账号存储、任务状态、对话恢复、自动化审计、额度归一化。其中有 8 种暂停与 18 种续做模拟，并覆盖重复操作编号、额度过期、缺失/耗尽窗口、身份不匹配、未确认恢复记录和重启后不重放。

候选与安装版主程序、ASAR、图标摘要一致，严格签名通过；覆盖前后全局 auth/config 摘要不变。安装版宿主及随包 helper 启动成功，私有连接返回 ready=true、trayVisible=true，helper 父进程匹配宿主；只读核验仍为指定 20 倍账号。helper 资源和图标与 0927v2 相同，本轮未重打包。
