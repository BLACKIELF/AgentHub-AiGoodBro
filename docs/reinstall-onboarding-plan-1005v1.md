# 安装后连接检查说明 · 1005v5

状态：127 本地预览在安装识别与连接检查基础上增加新用户／老用户选择。可识别的安装或覆盖后的首次打开先显示选择页；普通退出重启不重复呈现已完成或明确延后的引导。当前验证使用隔离文件、状态及消息控制器，不代表真实安装和消息送达已验收。

## 用户看到的流程

选择「我是新用户」后进入账号、运行环境、功能、通知和完成的完整引导。选择「我是老用户」后只进入微信／飞书连接、新功能和完成三页，保留账号、外观、反代和其他偏好，不触发系统通知权限检查。新功能设置复用现有自动使用重置卡、侧栏额度样式和显示开关；打开页面或完成引导不会开启功能。界面分别显示「待连接」「凭据已授权」「连接已恢复」与实际投递结果，不把跳过或本地凭据可读当成发送成功。

微信先提供恢复已保存连接的入口，凭据缺失或过期时再扫码。重连前检查微信消息是否仍在处理；忙碌时延后连接，不能因打开引导取消聊天任务。更换微信账号后，需要重新确认对话归属，不能自动沿用旧账号的手选对话。

飞书提供重新授权已有机器人地址的入口，缺少地址时再输入。授权成功只表示可读取本机保存的配置；只有用户明确点击「测试连接」才发送真实测试通知。

用户可以选择「以后再说」进入工作台；主页保留待连接入口。本次安装跳过后普通重启不再弹，下次安装仍会出现。关窗、崩溃和退出保留当前进度，不自动算作跳过或连接完成。

## 安装识别与最小实现

只比较版本号不能识别同一安装包的重复安装。受控安装在签名核验、空闲检查和替换成功后，原子保存独立的安装 UUID；引导完成或跳过绑定本次安装。普通启动不创建新 UUID，失败或回滚不确认新安装。安装记录放在应用独立的数据目录，不修改已签名的应用包。

现有 DMG 拖装没有安装完成钩子。可用原生文件身份检测整体替换作为回退，但保持文件身份的同内容原位覆盖无法可靠观察。兑现「每次安装」的验收条件，需要正式安装入口记录安装成功事件；仅版本变化或文件时间变化不算完成这一要求。

复用现有 `NextSetupGuideView`、引导状态与连接授权接口。启动前读取安装状态，新事件清除本次选择后打开选择页；选择与进度绑定同一事件，迟到的安装回执只补全标识，不改变当前选择、进度或终态。手动引导使用独立步骤状态，不能完成当前安装事件。分开处理明确跳过和中途关闭。微信保留在途任务守卫及绑定归属校验，飞书保留本次安装的连接确认状态。保留凭据、去重账本、读取位置、未决记录和任务恢复记录；未确认期间不会补发历史通知或重派旧消息。

## 验收条件

- 首次安装、新版本覆盖和同版本连续重装：在可识别的成功安装后，下一启动选择新用户／老用户，再进入对应引导。
- 普通重启、明确跳过、中途退出和崩溃：按本次安装状态恢复，避免重复弹出或丢失进度。
- 安装失败、签名失败、运行中拒绝、记录写入失败和回滚：旧应用与安装记录保持可恢复，不虚报成功。
- 微信在途任务、扫码更换账号、迟到的授权结果、未决消息与去重记录：不取消任务、不串用对话、不重发。
- 飞书授权拒绝、配置缺失、用户主动测试和启动后的完成事件：分别报告结果，不自动发送测试或历史通知。

受控安装回执写入失败会撤回新包并尝试恢复原安装位置，失败时保留可恢复目录，不启动新应用。回执和应用替换不是跨文件崩溃原子事务；文件身份暂不可读时不会推断为新安装。同一文件身份的回执从不可读恢复时，只补全 UUID，保留已完成、延期或中途进度。

隔离回归覆盖安装状态、同版 UUID、真实临时 Finder 整包替换、回执异常和失败恢复；原生预览及完整构建另行验证。真实用户的系统授权、手机微信和飞书送达不由这些检查代替。
