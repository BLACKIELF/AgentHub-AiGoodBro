# AiGoodBro 2.0 · 0927v4

相较 [0927v3](ai-goodbro-2.0-0927v3.md)，本次修复内嵌组件重复出现在 macOS Dock 的问题。内部版本 9.6.16（65），已覆盖安装到 `/Applications/AiGoodBro.app`。

## 本次变化

AiGoodBro 主程序保留 Dock 图标。Token Core 的应用包以 `LSUIElement` 启动，嵌入模式下窗口打开、恢复和设置变化始终使用 accessory 激活策略，避免启动闪现或打开窗口后再次出现第二个图标。独立 Token Monitor 安装与固定上游源码保持原样。

点击侧边栏的额度或用量项，沿用原有导航打开统计首页浮窗；悬停详情卡、拖动位置和实时速率切换保持原实现。仅新增宿主导航回调，没有重写侧边栏绘制、图标、尺寸或玻璃样式。

- 6 组桌面适配测试与 4 组打包检查通过；新增嵌入/独立模式的窗口激活检查，以及有效/无效来源、无效项、用量项和速率项的点击分支检查。
