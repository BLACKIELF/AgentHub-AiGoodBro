# 首次安装偏好

适用于 **2.5.1（146）· 1015v3**。首次安装偏好与老用户配置保留通过 117 条隔离断言，并纳入已通过的 35 组原生自测与完整本地构建。146 未覆盖安装，真实首次运行和系统快捷键实机验收仍待完成。

新用户使用以下通用界面默认值，并继续进入完整安装引导。这是一组公开默认值，不是维护者本机设置或数据的导出。

| 项目 | 首次安装默认值 |
| --- | --- |
| 主题模式 | 跟随系统（system） |
| 账号显示 | 卡片 |
| 屏幕边缘侧栏 | 自动隐藏 |
| 菜单栏 | 显示剩余额度与重置倒计时 |
| 用量趋势 | K 线，全部历史统计 |
| 玻璃 | 透明度 74%，深度 84% |
| 主窗口快捷键 | ⌘U |
| 侧栏快捷键 | ⌘I |

已有用户覆盖安装或重装时，保留全部已保存配置，包括关闭选择和自定义快捷键。新默认值不会用来覆盖已有偏好，也不携带账号、凭据、私人路径、服务端点或授权。

首次安装仍需用户连接自己的账号与工具；通知发送、重置卡自动使用等可选行为仍需用户选择与授权。打开介绍、完成引导或授予钥匙串访问，都不等于授权发送测试消息、使用重置卡或调用模型。

微信、飞书在升级后可能需要 macOS 钥匙串授权。按引导检查已有连接；配置可读、连接恢复、API 接收与手机收件分别核对。来源与本轮验证状态见 [2.5.1 发布说明](release-notes-v2.5.1.md)。

## English

Applies to **2.5.1 (146), release 1015v3**. First-install preferences and returning-user configuration passed 117 isolated assertions within the 35 native self-test groups and full local build. Build 146 has not been installed; real first-run behavior and system hotkeys still require device acceptance.

New users receive these general interface defaults and still enter the complete setup guide. These are public defaults, not an export of the maintainer's local settings or data.

| Setting | First-install default |
| --- | --- |
| Appearance | Follow system |
| Accounts | Cards |
| Edge sidebar | Auto-hide |
| Menu bar | Remaining quota and reset countdown |
| Usage trends | Candlesticks, all-time statistics |
| Glass | Transparency 74%, depth 84% |
| Main-window shortcut | ⌘U |
| Sidebar shortcut | ⌘I |

Replacement installations and reinstalls preserve all saved configuration, including disabled choices and custom shortcuts. These defaults do not overwrite existing preferences and contain no accounts, credentials, private paths, service endpoints or permissions.

Users still connect their own accounts and tools. Notification sending, automatic reset-card use and other optional actions require user choices and authorization. Viewing an introduction, finishing onboarding or granting Keychain access does not authorize test messages, card redemption or model calls.

WeChat and Feishu may need macOS Keychain permission after an upgrade. Review connections through onboarding; readable configuration, restored connections, API acceptance and phone delivery are separate states. See the [2.5.1 release notes](release-notes-v2.5.1.md) for scope and validation status.
