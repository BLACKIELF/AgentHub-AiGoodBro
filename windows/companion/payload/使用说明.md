# Windows 配套工具使用说明

在 AiGoodBro 的运行环境引导中检查已安装的 Python 和 Codex CLI，选择现有可执行文件。Python 必须通过版本、标准库、时区能力与文件身份检查；软件不自动安装 Python。

选择安装配套工具后，先查看实际文件差异，再单独确认。旧用户正文、未托管文件和旧的 dispatch-codes/policy 配置保留；原生账号目录和 workflow 设置是唯一调度来源。更新前备份，发生并发修改时拒绝覆盖，失败不显示已保存。

应用、账号和任务服务由用户已有操作启动。这里不会自动打开 App。安装后按 `references/runtime-setup.md` 调用真实客户端。退出应用或选择的 Python、App 文件、任务范围变化后，旧绑定不能继续冒充可用；回到应用重新核对。

安装成功、服务可用、已提交任务、进程退出、产物验收是不同状态。未知提交只查原记录，不重复派单。恢复入口只处理本次安装仍匹配的改动，不接管其他文件或任务。
