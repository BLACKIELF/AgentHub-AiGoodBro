# 连接工具与账号

在 AiGoodBro 的账号管理中创建或选择独立账号，使用现有官方登录入口，等待真实身份验证完成。登记与主页/任务可选映射成功后，再在 Tasks 中选择数字 profile 和项目。登录页面结束、账号卡出现或打开浏览器，都不能替代验证结果。

首次登记默认参与行为和已有用户 opt-out 按 App 原生规则保存。Skill 不修改参与开关、备注、额度阈值或全局认证，不复制 token 到脚本。网页登录账号池和 CLI/受控账号池是不同入口，不能混用凭据。

Python 与 Codex 路径选择在运行环境引导完成。更新 Skill 只处理经确认的托管文件；不替用户登录、不安装其他工具、不请求模型来测试“是否在线”。其他 CLI、Jev、Grok 或原聊天写入能力必须各自有真实合同和验证，不能由本工具的安装状态推断。
