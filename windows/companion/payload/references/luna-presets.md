# 模型、强度与执行档位

当前 Windows Companion 使用已连接账号在 App 中保存的有效 model/effort 和调度策略。预检、预约、批准及最终启动检查绑定这些设置和 revision；期间变更必须重新准备，不能悄悄使用旧值。

当前客户端不支持本次调用单独传入 model、effort 或 tier，也不解析 Mac 的字母账号/档位别名。原生协议对这些非空覆盖字段明确拒绝，而不是接受后忽略。不要写成三个档位已迁移，或在 Skill 中增加未验证的模型名。

用户明确指定的参数优先；若当前入口表达不了，就报告确切限制并停止该次启动。在已授权范围内补齐并验证后再执行，不静默改用保存偏好，也不改永久设置来冒充单次覆盖。
