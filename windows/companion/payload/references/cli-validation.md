# 调用证据与验收

这里的 launcher 只通信，不直接运行模型 CLI。它验证已安装配置、选定 Python、App 来源绑定、私有 IPC 端点和连接进程；随后 App 复核原生账号与工作范围。不要从文件存在、--help、退出码 0 推断身份、网络或模型已经可用。

服务端接受当前范围后，任务创建与批准仍复用现有 Hub 的身份、额度、参与策略和最终启动检查。客户端输出 accepted 不是模型成功；最终状态 awaitingAcceptance 需要读取实际交付物并执行相应验证。

明确的未发送错误可以在修正原因后重新准备。写入可能已经发生后的 unknown 只能查询原 operation ID，不自动重放。非零退出也可能已经造成部分工作，重新安排前先核已有产物和原任务。

Windows 原生 pipe/owner、实际安装资源以及真实模型各自独立验收。离线合成测试不代表真实账号运行，也不替代用户设备验证。
